## V9 아군 부대 · 국회의사당 실내

아군 30명(탑승 담당 8명, 보병 22명)을 추가했습니다. 파란 군복과 초록 미니맵 표시로 구분합니다. 탑승 담당은 근처의 비어 있는 탱크·헬기·전투기·수송기를 찾아 탑승하고 적을 사격합니다. 아군 지원용 장비는 종류별 2대씩 8대를 추가했습니다. 보병은 근처 적을 향해 이동·사격·재장전하며, 적은 플레이어와 아군 중 보이는 표적을 공격합니다. 차량이 파괴되면 탑승 아군도 사망하며 아군 사망은 적 제압 수에 포함하지 않습니다. 보병 경로는 지역 충돌 회피이며 복잡한 도시 전체의 경로 탐색은 아닙니다. 수송기는 게임용 지원 사격을 합니다.

국회의사당은 게임용으로 단순화한 가상 실내입니다. 실제 도면·배치의 재현이 아닙니다. 정문·후문, 로비, 본회의장, 양쪽 사무 공간, 책상·의자·연단·조명, 중앙 이동 통로와 벽 충돌을 구현했습니다. 기존 300명 중 8명을 내부 적으로 재배치했습니다. G 지역 이동 → 국회의사당 · 로비 / 본회의장으로 이동하거나 걸어서 출입할 수 있습니다.

아군의 현재 체력·탑승 상태는 저장하지 않으며 재시작·저장 복원 시 아군 부대와 지원 장비가 다시 생성됩니다. 적 제압 기록은 기존 방식으로 저장합니다. 기존 적 장비의 60초 대기 및 12초 간격 출격은 유지합니다. 자동 검사 31개와 모의 게임 통합 검사에서 병력 수·8명 탑승·재장전과 사격·수송기 이륙·양측 표적·아군 사망·재시작·국회 출입구와 벽의 충돌 및 탄환 차단을 확인했습니다. 실제 브라우저의 시각적 품질·성능은 아직 확인하지 못했습니다.

## V8 RPG · 순차 증원

5번 키로 기본 지급 RPG를 선택합니다. 모바일은 무기 전환 버튼으로 선택합니다. 1발 발사 후 R(모바일 재장전)로 재장전하며 예비 미사일 8발, 탄약 상자로 보급됩니다. 미사일은 초속 180m로 최대 1,400m를 비행하고 물체·지면·벽에 충돌하면 범위 피해를 줍니다. 자동 유도 기능은 없습니다. 탱크·헬기·전투기 차체 명중 시 피해와 남은 장갑을 표시하며 파괴하면 탑승병을 제압합니다.

적 장비는 플레이 시간 60초 전까지 보이지 않고 이동·공격·피격하지 않습니다. 60초부터 탱크 → 헬기 → 전투기 순으로 12초마다 1대씩 총 12대 출격합니다. 일시정지 중에는 시간이 흐르지 않습니다. 기본 탑승용 장비는 이 출격 대기에 포함하지 않습니다. 저장 복원 시 살아 있는 장비를 순차 재출격시킵니다.

4칸 구버전 저장은 5칸으로 이전하며 RPG를 지급합니다. Firebase 기존 규칙에서는 selected 상한을 4로, inventory 허용 인덱스에 4를 추가해야 합니다. 업데이트한 firebase-rules.fragment.json을 기존 규칙에 병합하세요. 실제 운영 Firebase 설정·브라우저 화면은 확인하지 못했습니다. 자동 검사 31개 및 모의 게임 통합 검사로 시간 경계·출격 간격·실제 RPG 발사와 폭발·차체 명중·재시작·저장 이전을 확인했습니다.

## 신호와 정체

동서·남북 방향의 녹색·황색·적색 주기를 분리했습니다. AI 차량은 빨간불의 정지선에서 멈추고 앞차와 간격을 유지하며, 녹색으로 바뀌면 출발합니다. 이 과정에서 차량 대기 행렬과 정체가 발생합니다. 방향별 동적 신호 표시기 80개가 있고 지도에서 대기 차량을 확인할 수 있습니다.

이것은 제한된 생성 간선 루프를 따르는 단순 교통 모형입니다. 실제 도로별 통행량·차선 변경·사고·주차·현실적인 교차로 회전·보행자 신호 준수 전체를 시뮬레이션하지 않습니다. 사용자가 운전하는 차량의 신호 준수를 강제하지 않습니다. 지형을 지나는 생성 연결 구간은 현실 도로 공학을 재현한 것이 아닙니다.

## 공항과 항공기

김포·인천 이름의 생성 터미널에 실제로 걸어 들어갈 수 있습니다. 출입구·체크인 카운터·모니터·탑승 대기 좌석·게이트 안내·수하물 회전대 형태의 구역·유리 외벽·활주로·격납고·계류장을 배치했습니다. 내부 배치와 절차는 실제 공항과 다르며 항공권·출입국·보안 절차를 시뮬레이션하지 않습니다.

F-16을 참고한 전투기에는 단발 동체·흡입구·버블 캐노피·후퇴익·수직 꼬리날개를 구성했습니다. 민항 제트기는 긴 객실 동체·양쪽 날개·쌍발 엔진·높은 꼬리날개를 갖습니다. 공항에 세워진 민항기와 가상 훈련기지의 전투기에 탑승해 조종할 수 있습니다. 비행은 단순한 아케이드 조작이며 정밀 비행 시뮬레이터가 아닙니다.
