# NIGHTFALL — SEOUL OPERATIONS / V3

서울을 배경으로 강남·강북과 한강, 주요 명소를 재구성한 브라우저 싱글플레이 FPS 프로토타입입니다. 약 850 × 850m 안에서 이동하기 좋도록 위치·거리·건물 비율을 축약한 **가상 지도**이며 실제 서울의 정밀 복제나 내비게이션 지도가 아닙니다.

게임: https://mingeon101.github.io/nightfall-fps/?v=3

## 서울 배경

- 한강을 중심으로 강북과 강남권을 구분했습니다. 강변북로·올림픽대로와 보행로, 한강공원을 표현했습니다.
- 마포대교·반포대교·한남대교를 모티프로 한 다리 3개로 도보·차량 이동이 가능합니다. 다리가 없는 수면에는 진입할 수 없습니다.
- 강북 명소: 청와대의 푸른 지붕과 중앙·양측 건물, 경복궁의 근정전·경회루·사정전·광화문과 담장·마당, 북촌 한옥, 서울시청, 서울역, DDP, 남산서울타워, 북악산과 남산.
- 강남권 명소: 코엑스·무역센터, 롯데월드타워, 강남역·테헤란로, 여의도의 국회의사당·63빌딩, 백화점.
- 강남·강북의 밀집 아파트 단지: 높이가 다른 동, 창문, 측면 발코니와 동 번호 표지. 학교·경찰서·소방서·병원 등 생활 시설도 배치했습니다.
- 차선·중앙선·횡단보도·신호등·도로명 표지와 양방향 순환 차량 16대, 주차 차량 및 택시 형태의 차량. 신호등은 장식이며 교차로 신호 체계는 시뮬레이션하지 않습니다.
- 미니맵에 한강, 세 다리, 강남·강북, 산, 도로를 표시합니다. M으로 확대하면 주요 명소 이름도 볼 수 있습니다.

## 유지한 게임 기능

적 16명의 이동·사격·재장전·쓰러짐, 민간인 32명의 보행·총성 회피, 점프·달리기·체력 회복, 총기 4종, 방탄복·탄약·구급상자, 차량 탈취·운전, 전차·수송기·전투기·헬리콥터의 탑승과 단순 조종을 유지했습니다. 항공기와 전차가 있는 남서쪽 훈련 구역은 **게임용 가상 시설**이며 실제 서울 시설을 재현하지 않습니다.

지하철은 종로·광화문, 왕십리·성수, 강남·삼성, 여의도·서초의 게임용 역을 연결합니다. 게임 1호선은 강북 두 역을 연결하고 게임 2호선은 두 강변을 순환합니다. 이전 버전의 플레이를 유지하기 위한 **가상 노선으로, 실제 서울 지하철 노선·역 위치와 다릅니다.** 선택한 경로를 따라 지하 열차로 이동한 뒤 지상 출구로 나옵니다.

## 조작

| 입력 | 기능 |
| --- | --- |
| WASD | 도보 이동 / 차량 가속·후진·선회 |
| 마우스 | 시점, 좌클릭 사격, 우클릭 조준 |
| SPACE | 점프 / 항공기 상승 |
| Q | 항공기 하강 |
| Shift | 달리기 / 차량 브레이크 |
| E | 아이템 획득, 차량 탑승·하차, 역 이용 |
| R | 소지 탄약으로 재장전 |
| 1–4 | 획득한 무기 변경 |
| M | 지도 확대·축소 |
| ESC | 일시정지 |
| 방향키 | 마우스 잠금이 제한된 환경의 시점 조작 |

강북 성수 방면에서 시작하며 근처에 보급품이 있습니다. 항공기는 W로 가속 후 SPACE로 이륙합니다. 헬리콥터는 수직 이륙할 수 있습니다. Q로 하강하고 Shift로 감속한 뒤 지면에서 E로 하차하세요.

## 실행·배포

저장소 루트를 정적 HTTP 서버로 제공하거나 GitHub Pages를 사용하세요. Pages는 Deploy from a branch → main → /(root)이며 빌드 과정이 없습니다. PC 키보드·마우스, WebGL과 인터넷 연결이 필요합니다. Three.js는 jsDelivr, 글꼴은 Google Fonts에서 불러옵니다.

## 검증과 범위

`node --test tests/core.test.mjs`로 11개 회귀 검사를 실행할 수 있습니다. 서울 구역, 산과 강, 다리 이동과 수면 진입 차단, 총격 차폐, 방탄복, 지하철, 차량 조작과 이륙, 하차 안전성 등을 검사합니다. 별도 렌더링 대역 기반 통합 검사에서 도시 초기화, NPC·차량 배치, 명소, 보급품·차량·역 접근성, 양방향 차량의 전체 경로, 점프·착지, 적 재장전·쓰러짐, 탑승·하차·지하철·재시작을 확인했습니다.

건물은 외관 중심이며 실내는 없습니다. 차량·비행과 관절 애니메이션은 단순화했습니다. 실제 브라우저의 화면·성능·조작감 검증은 아직 수행하지 못했습니다. 모바일 터치 조작, 저장, 차량 파괴·차량 간 충돌·물리 래그돌은 지원하지 않습니다.
