## V14 전투기 열추적 미사일 · 플레어

Z는 플레어 1회를 사출합니다(6회, 재사용 대기 6초). 비행 중에는 약 1.5초간 자동 선회·상승과 기울임을 적용합니다. 플레어는 일부 미사일을 교란할 수 있지만 무조건 방어하지는 않습니다. 지상에서는 플레어만 사출하고 자동 상승하지 않습니다. 현실 무기의 성능·운용을 재현하지 않는 간단한 게임 규칙입니다.

- Firebase의 **Google 로그인**, **전화번호+SMS 인증**, **RTDB 사용자별 저장·불러오기**를 구현했습니다. 사용자 제공 프로젝트 설정을 연결했습니다. Analytics 수집 코드는 실행하지 않습니다.
- 첫 저장 또는 불러오기 후 플레이 중 30초마다 자동 저장합니다. 위치·체력·방탄복·소지금·무기·탄약·제압 기록을 저장합니다. 계정별 UID 경로와 기기 간 revision 충돌 처리를 사용합니다.
- **Firebase 콘솔에서 로그인 제공업체·허용 도메인·SMS 설정과 RTDB 규칙을 확인/적용해야 합니다.** 현재 도구로 해당 관리자 설정은 변경하지 못했습니다. [FIREBASE-SETUP.md](FIREBASE-SETUP.md)의 안내와 병합용 규칙 조각을 참고하세요.
- 실제 Google 로그인·SMS 발송·운영 RTDB 쓰기는 대신 실행하지 않았습니다. 자동 검사는 모의 SDK와 입력 이벤트를 이용했습니다. 실기기 모바일 화면·성능·터치 감각 검증도 아직입니다.

## 확장한 도시

- 추가 생성 건물 **3,256개**: 아파트·업무 빌딩·상가와 대표 생활 시설. 기존 도심 명소도 유지했습니다.
- 사람 **272명**: 도심과 한강공원의 보행 시민, 기존 전투 AI. 가까운 인물을 중심으로 갱신·표시합니다.
- 차량 **82대**: 시민 차량·택시·탑승 가능한 지상 차량과 항공기. 공항 주변의 별도 자동 비행 민항기 2대도 있습니다.
- **25개 편의점**: 문으로 걸어 들어갈 수 있고 진열대와 계산대가 있습니다. 계산대 근처에서 E로 생수·도시락·응급 키트를 구매할 수 있습니다. 초기 소지금 50,000원이며 구매 시 체력을 회복합니다.
- 구청·병원·학교·경찰서·소방서·은행·약국·카페·시장·호텔 등의 대표 시설 외관을 생성했습니다. 모든 실제 시설을 수록하거나 모든 건물의 실내를 구현한 것은 아닙니다.
- 한강공원 6개 구역: 잔디·산책로·운동 코트·벤치·보행 시민. 다리 11개 모티프와 북한산·도봉산·관악산·아차산 등의 개략 산 지형.
- 지역별 시가지는 공간 단위로 나누고, 가까운 부분을 표시합니다. 충돌 검사는 공간 색인으로 가까운 건물부터 확인합니다. 실제 기기의 프레임 성능은 아직 측정하지 못했습니다.

## 신호와 정체

동서·남북 방향의 녹색·황색·적색 주기를 분리했습니다. AI 차량은 빨간불의 정지선에서 멈추고 앞차와 간격을 유지하며, 녹색으로 바뀌면 출발합니다. 이 과정에서 차량 대기 행렬과 정체가 발생합니다. 방향별 동적 신호 표시기 80개가 있고 지도에서 대기 차량을 확인할 수 있습니다.

이것은 제한된 생성 간선 루프를 따르는 단순 교통 모형입니다. 실제 도로별 통행량·차선 변경·사고·주차·현실적인 교차로 회전·보행자 신호 준수 전체를 시뮬레이션하지 않습니다. 사용자가 운전하는 차량의 신호 준수를 강제하지 않습니다. 지형을 지나는 생성 연결 구간은 현실 도로 공학을 재현한 것이 아닙니다.

## 공항과 항공기

김포·인천 이름의 생성 터미널에 실제로 걸어 들어갈 수 있습니다. 출입구·체크인 카운터·모니터·탑승 대기 좌석·게이트 안내·수하물 회전대 형태의 구역·유리 외벽·활주로·격납고·계류장을 배치했습니다. 내부 배치와 절차는 실제 공항과 다르며 항공권·출입국·보안 절차를 시뮬레이션하지 않습니다.

F-16을 참고한 전투기에는 단발 동체·흡입구·버블 캐노피·후퇴익·수직 꼬리날개를 구성했습니다. 민항 제트기는 긴 객실 동체·양쪽 날개·쌍발 엔진·높은 꼬리날개를 갖습니다. 공항에 세워진 민항기와 가상 훈련기지의 전투기에 탑승해 조종할 수 있습니다. 비행은 단순한 아케이드 조작이며 정밀 비행 시뮬레이터가 아닙니다.

## 대중교통

- 지하철 거점 **32개**, 노선별 승강장 **38개**, 2량 전동차 **3편성**.
- 기존 게임 1·2호선과 추가 게임 3호선(도시 연결선)으로 지역·공항·훈련기지 거점을 연결합니다. 실제 서울 지하철 3호선과 다릅니다.
- 지상 입구 E → 노선·목적지 선택 → 승강장 대기 → 열차가 정차하고 스크린도어가 열리면 문 앞에서 E 승차.
- 목적지에서 문이 열리면 E 하차 → 승강장 끝 녹색 출구 계단에서 E로 지상 이동.
- 버스 정류장 **32개**. 정류장에서 잠시 기다리면 버스가 접근·정차하고 문을 엽니다. E로 탑승하고 다음 정류장에서 E로 내립니다.
- 승강장·전동차 객실·스크린도어·좌석·역명 표지·정류장 쉼터를 유지·확장했습니다.
- 모든 교통 연결은 생성형 게임 노선이며, 실제 운행·수요·역 구내·지하 구조를 재현하지 않습니다.

## 조작

| 입력 | 기능 |
| --- | --- |
| WASD | 도보 이동 / 차량 가속·후진·선회 |
| 마우스 | 시점, 좌클릭 사격, 우클릭 조준 |
| SPACE / Q | 점프·항공기 상승 / 항공기 하강 |
| Shift | 달리기 / 차량 브레이크 |
| E | 아이템·계산대·차량·대중교통 상호작용 |
| R / 1–4 | 재장전 / 획득한 무기 변경 |
| M | 주변 지도 ↔ 서울 전역 지도 |
| G | 25개 구·공항·가상 훈련기지 이동 메뉴 |
| ESC | 일시정지 |
| 방향키 | 마우스 잠금이 제한된 경우 시점 조작 |

큰 지역을 둘러볼 때는 G로 이동할 곳을 고르세요. 공항 이동 후 남쪽(정면) 출입구를 향해 걸으면 터미널에 들어갑니다. 항공기는 W로 가속하고 SPACE로 상승합니다. Q로 하강하고 Shift로 감속한 뒤 정지·착륙 상태에서 E로 내립니다.
