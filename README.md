# NIGHTFALL — CITY OPERATIONS / V2

중앙산을 둘러싼 850 × 850m 도시를 탐색하는 독창적인 브라우저 싱글플레이 FPS 프로토타입입니다. 외부 게임의 맵·음원·캐릭터 자산을 사용하지 않습니다.

## 구현한 기능

- 산업지구: 창고, 물류센터, 컨테이너 야드, 공장 굴뚝.
- 주거지구: 밀집 아파트, 학교, 경찰서, 소방서, 종합병원, 시청.
- 군사지구: 공항 터미널, 활주로, 격납고, 관제탑, 지휘부, 병영.
- 상업지구: 백화점, 아울렛, 쇼핑몰, 밀집 상가.
- 중앙산: 실제 고도와 시야·총격 차폐가 있는 지형.
- 적 16명: 소총을 들고 이동·조준·사격하며 탄창 소진 후 팔·탄창을 움직여 재장전합니다. 제압되면 넘어지고 시체가 남습니다.
- 민간인 32명: 거리를 걷고 총성을 들으면 달아납니다. 민간인은 무장하지 않으며 사격 대상이 아닙니다.
- 플레이어 점프, 달리기, 조준, 유한 탄약·재장전, 체력 회복.
- 돌격소총·기관단총·산탄총·저격소총 획득과 교체. 방탄복, 탄약, 구급상자 보급품(45초 후 재생성).
- 미니맵 및 확대 지도: 지구·건물·산·도로·역·두 지하철 노선·플레이어·적·시민·차량·아이템 표시.
- 도로를 순환하는 자동차 12대 및 주차 차량. 가까이에서 E로 탈취·탑승한 뒤 직접 운전할 수 있습니다.
- 군사지구의 전차 2대, 수송기, 전투기, 헬리콥터 탑승 및 조종. 전차·전투기·헬리콥터에는 사격 가능한 무장이 있습니다.
- 지하철 1호선: 산업단지 ↔ 주거중앙. 2호선: 산업단지 → 주거중앙 → 상업중앙 → 공항·군사기지 → 산업단지 순환. 실제 지하 터널과 움직이는 열차를 배치했습니다. 역에서 노선과 목적지를 선택하면 해당 경로를 따라 이동합니다. 2호선 승차 경로는 두 방향 중 짧은 쪽입니다.
- 모든 적 제압 후 도시 자유 탐색, 사망 시 전체 상태 초기화 후 재도전.

## 조작

| 입력 | 기능 |
| --- | --- |
| WASD | 도보 이동 / 차량 가속·후진·선회 |
| 마우스 | 시점, 좌클릭 사격, 우클릭 정밀 조준 |
| SPACE | 점프 / 항공기 상승 |
| Q | 항공기 하강 |
| Shift | 달리기 / 차량 브레이크 |
| E | 가까운 아이템 획득, 차량 탑승·하차, 역 이용 |
| R | 소지 탄약으로 재장전 |
| 1–4 | 획득한 무기 변경 |
| M | 지도 확대·축소 |
| ESC | 일시정지 |
| 방향키 | 마우스 잠금을 사용할 수 없을 때 시점 조작 |

항공기는 W로 속도를 올린 다음 SPACE로 이륙합니다. 헬리콥터는 정지 상태에서도 수직 이륙합니다. Q로 하강하고 Shift로 감속하세요. 지면에서 속도가 충분히 낮을 때 E로 내릴 수 있습니다. 탑승 가능한 차량은 지도에 표시됩니다. 주거지구에서 시작하며, 근처에 기관단총·방탄복·탄약·구급상자가 있습니다.

## 실행·배포

저장소 루트를 정적 HTTP 서버로 제공하거나 GitHub Pages를 사용하세요. Pages 설정은 Deploy from a branch → main → /(root) 입니다. 빌드 단계가 없으며, main이 업데이트되면 활성화된 Pages가 새 버전을 게시합니다. PC 키보드·마우스 및 WebGL 지원 브라우저가 필요합니다. Three.js는 jsDelivr, 글꼴은 Google Fonts에서 불러옵니다. 인터넷 연결이 필요합니다.

게임 주소: https://mingeon101.github.io/nightfall-fps/

## 검사

Node.js에서 `node --test tests/core.test.mjs`로 10개 회귀 검사를 실행할 수 있습니다. 구역, 산, 연속 충돌, 높이별 총격 차폐, 방탄복 내구도, 두 지하철 노선, 5개 차량 조작과 이륙, 하차 안전성, 무기별 차이를 검증합니다. 별도 렌더링 대역 기반 통합 검사로 도시 초기화, 모든 NPC의 배치, 역·차량·아이템 접근성, 점프·착지, 적 재장전·쓰러짐, 아이템 획득, 탑승·하차, 지하철 이동, 재시작을 확인했습니다.

## 현재 범위

형태와 동작을 코드로 만든 프로토타입입니다. 건물은 외관 중심이며 실내 진입을 제공하지 않습니다. 차량·항공기·전차는 단순화한 아케이드 조작이고 현실적인 비행 역학, 차량 파괴, 차량 간 충돌, 민간인 운전자 하차 애니메이션은 없습니다. 지하철은 목적지를 선택해 탑승하는 방식으로, 플랫폼에서 자유롭게 걸어 다니는 시스템은 아닙니다. 적의 쓰러짐은 관절 애니메이션이며 물리 래그돌은 아닙니다. 모바일 터치 조작과 저장 기능은 없습니다. 실제 브라우저에서의 화면·성능·조작감 검증은 아직 수행하지 못했습니다.
